# 科哞哞——Codex 桌宠

**科哞哞**（Ke Mou Mou）是一位穿着奶油白小牛连帽装、蓝色 USTC 上衣、背着地球挎包的卡通女孩，作为中国科学技术大学本科科研实践平台的互动形象而设计。本项目公开角色设计、**桌面端宠物安装包**及独立的**网页伙伴演示**。代码采用 MIT 许可；角色图片、动画与创作素材仅限署名、非商业使用。

## 设计思路

### 灵感来源

"科哞哞"的名字取自"科大"的"科"与牛叫声"哞哞"的叠音，亲切而便于记忆。角色设计灵感来源于中国科学技术大学校园中广受喜爱的"科小牛"文创形象及"孺子牛"校园雕塑——小牛推动地球的意象，象征着求知与探索。

### 造型语言

- **奶油白牛头套**与**金色牛角**：呼应科大"科小牛"的视觉记忆，毛绒质感传递温暖
- **蓝色上衣与 USTC 字样**：建立学校关联，深蓝代表沉静与严谨
- **地球斜挎包**：延续"牛与世界"的校园联想，象征面向世界的好奇心
- **棕色短发与大眼**：保持学生般的好奇与亲切感
- **大头与紧凑身体**（约 2.8 头身）：强化卡通感，适合小尺寸显示
- **毛绒领口贴合下巴**：不露出脖子，让角色显得温暖而有安全感

### 从角色到桌宠

角色设计完成后，我们将科哞哞适配为 Codex 桌宠格式：保留全部视觉特征，将角色绘制在 192x208 像素的单元格中，使用绿幕抠像（chroma key #00FF00）提取透明背景，最终拼接为精灵图表（spritesheet）。扩展精灵图包含 9 种动画状态和 2 行视线跟随帧，包括待机、奔跑、跳跃、挥手、出错、等待、思考、检查成果以及 16 方向视线跟随。

## 动画状态

Codex 桌宠版本的科哞哞支持以下动画状态：

| 状态 | 帧数 | 描述 |
| --- | --- | --- |
| `idle` | 6 | 安静陪伴，轻轻呼吸和眨眼 |
| `running-right` | 8 | 向右拖动时奔跑 |
| `running-left` | 8 | 向左拖动时奔跑 |
| `waving` | 4 | 打招呼，蹄形手套轻轻挥手 |
| `jumping` | 5 | 开心跳跃，蓄力、起跳、腾空、落地 |
| `failed` | 8 | 出错时委屈大哭，张嘴流泪 |
| `waiting` | 6 | 等待输入，双手靠拢抬头期待 |
| `running` | 6 | 认真思考，双脚站稳托腮 |
| `review` | 6 | 检查成果，低头观察地球挎包 |
| `look-row-9` | 8 | 视线跟随：从上方顺时针至右下方（0°–157.5°） |
| `look-row-10` | 8 | 视线跟随：从下方顺时针至左上方（180°–337.5°） |

网页演示使用扩展精灵图 `sprites/final/spritesheet-extended.png`：1536×2288 像素、73 个有效帧、11 行×8 列。桌面安装包使用九行动画图：1536×1872 像素、57 个有效帧。每格均为 192×208 像素，未使用的格子透明。

扩展图的部分中间视线方向变化较细微，历史质量报告保留了透明孔隙和方向连续性提示，见 [pet-quality.json](sprites/qa/pet-quality.json)。这些是已有画作的已知视觉局限，不表示所有质量指标均无警告。

## 部署 Codex 桌宠

### 桌面端安装

本仓库提供 `codex/kemoomoo/` 本地宠物包。它与本机已安装桌宠的 `pet.json` 格式一致，使用九行动画图；扩展图的十六方向视线跟随只在本仓库网页演示中验证。

1. 下载本仓库，将 `codex/kemoomoo/` 整个文件夹复制到 `~/.codex/pets/kemoomoo/`。若设置了 `CODEX_HOME`，使用其下的 `pets/kemoomoo/`。已有同名宠物时先备份，避免覆盖。
2. 打开桌面应用的 Settings → Pets，刷新列表后选择「科哞哞」。旧版本可能需要重启应用。
3. 使用 `/pet` 显示桌宠。

上述本地目录格式依据本机已安装包核对；未在所有桌面应用版本上实测。当前官方文档介绍的入口见 [Pets](https://learn.chatgpt.com/docs/pets)。网页端 Upload pet 要求九行图，可使用 [spritesheet.png](codex/kemoomoo/spritesheet.png)，不要上传十一行扩展图。桌面包不负责同步到网页账户。

### 网页演示

在仓库根目录运行：

```bash
python -m http.server 8080 --bind 127.0.0.1 --directory web
```

打开 <http://127.0.0.1:8080/>。也可以运行 `npx serve web` 并打开命令输出的地址。

网页伙伴支持拖动、九种动作、视线跟随、章节介绍、大小调节与偏好保存。它不读取桌面应用的任务状态。

### 集成到自己的网站

将 `web/pet.js`、`web/pet.css` 与 `web/pet/` 复制到网站的 `assets/` 目录，然后引入：

```html
<link rel="stylesheet" href="/assets/pet.css">
<script src="/assets/pet.js" data-site-base="../" defer></script>
```

若网站部署在子目录，例如 `/my-site/`，应将上面的资源路径改为 `/my-site/assets/...`。默认使用当前页面的真实章节生成导航；Cutus 个人站专用导航需显式启用。更多说明见 [DEPLOYMENT.md](DEPLOYMENT.md)。

发布前可按 [TESTING.md](TESTING.md) 执行资源校验和浏览器回归检查。

## AI 辅助创作说明

本项目的角色设计和桌宠制作均使用了 **OpenAI Codex** 的内置 imagegen 工具辅助完成：

- **角色概念图**：使用 imagegen 根据文字提示词生成角色插画，经多轮人工选择和修改确定最终造型
- **动作延展**：以选定主形象为参考，AI 辅助生成九种科研平台场景动作
- **桌宠精灵图**：逐状态使用 imagegen 生成动画帧，再通过脚本完成抠图、帧提取、拼接与校验
- **文字说明**：设计文档和说明文字由 AI 辅助起草，经作者最终审阅

公开的动画提示词与概念图创作记录保存在 `sprites/prompts/` 和 `design/概念图/`；部分投稿阶段内部日志和 PSD 未分发，历史记录中的提及不代表文件已包含在仓库中。
