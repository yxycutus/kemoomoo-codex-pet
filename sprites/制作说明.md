# 科哞哞 · ChatGPT 桌宠

## 需求与参考

参考原目录「科哞哞」的投稿主形象，制作 ChatGPT 自带桌宠。原目录仅用于读取，所有新增素材与制作记录保存到本目录。

保留奶油白小牛连帽装、金色牛角与蹄形手套、棕色短发和眼睛、蓝色 USTC 上衣、斜肩带与地球挎包。保持柔和插画风格，并使轮廓在桌宠尺寸下清晰。

## 动作设计

| 状态 | 设计 |
| --- | --- |
| 待机 | 轻轻呼吸、眨眼，双脚站稳 |
| 向右拖动 | 朝右奔跑，双腿交替、手臂摆动 |
| 向左拖动 | 单独绘制左向奔跑，保持衣服文字和挎包方向 |
| 打招呼 | 蹄形手套轻轻挥手 |
| 跳跃 | 蓄力、起跳、腾空、下落、落地 |
| 出错 | 委屈缩肩、张嘴大哭，泪水附着脸颊 |
| 等待输入 | 双手靠拢，抬头期待回应 |
| 工作中 | 双脚站稳，托腮思考 |
| 检查成果 | 低头观察自身地球挎包，认真检查 |
| 视线跟随 | 身体站稳，头部和目光自然跟随十六个方向 |

## 制作方式

新绘图像使用内置 imagegen。逐状态生成画面，再使用 work-pets 技能附带脚本完成抠图、帧提取、拼接与校验。具体提示词保存在 prompts，参考图副本保存在 references。
